# FPGA Deployment of AI for Science and Engineering

**Neural Electromagnetic Models for Electrical Machines** is the website for a research project on deploying neural electromagnetic field models on an AMD ZCU102 Zynq UltraScale+ MPSoC.

Live site: https://zwl20085.github.io/fpga-neural-em/

This is a static site: plain HTML, CSS and JavaScript, with no build step and no dependencies.

## Edit project details

`assets/js/site-config.js` holds the editable values: the repository links (add a URL **only** once a repository is public) and the last-updated date. The page `<title>`, description and Open Graph tags are at the top of `index.html`.

## Preview locally

```bash
python -m http.server 8765
# open http://localhost:8765/
```

## Deploy

GitHub Pages serves the `main` branch root. Pushing to `main` republishes the site in about a minute. Any other static host also works: upload the repository contents as they are.

## Assets

- `assets/img/hero-field.svg`: illustration generated by `tools/make_hero_svg.py` from a synthetic analytic potential. It is **not** simulation output.
- `assets/img/model-datapath.svg`: hand-drawn schematic of the model family.
- `assets/img/og-image.png`: social card, rendered with `python tools/og_and_check.py og` (requires Playwright).
- `python tools/og_and_check.py shots OUTDIR`: desktop/mobile screenshots, plus checks for broken anchors, broken images, missing alt text and console errors (expects the local server on :8765).

## Factual sources

ZCU102 hardware facts are taken from AMD UG1182 (v1.7, Feb. 2023). No FPGA results, speed-ups or power figures are claimed, because none exist yet.
